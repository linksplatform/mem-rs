Struct AsyncFileMem 

Source 
pub struct AsyncFileMem<T: Copy + Send + 'static> { /* private fields */ }
Expand description

Asynchronous file-backed memory storage using a dedicated I/O thread.

This type wraps FileMapped<T> and runs all mmap operations on a single dedicated thread. Async callers submit commands through a channel and receive results without being blocked by page faults.

No additional memory buffers are allocated — the mmap is the sole data store.
